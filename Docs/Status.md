# Last Ride Home — สถานะโปรเจกต์ (สรุปทั้งหมด)

เกม: **ตุ๊กตุ๊กรอบสุดท้าย / Last Ride Home** สำหรับ NEXT-SHAPE "ปั้นโลก" — side-scroll 8-bit ขับตุ๊กตุ๊กส่งผีผู้โดยสารก่อนฟ้าสาง (เยาวราช → อยุธยา → สุโขทัย → ภาคเหนือ → ดอยสุเทพ)

## ทำแล้ว
- Concept, Concept Paper, Unity prototype (ขับ, จอดคุยที่ (!), คัตซีน, รับ/ไม่รับ, 4 ฉากจบ, ไม่มี game over, นาฬิกาก่อนฟ้าสาง)
- ฟอนต์ไทย + แก้สระ/วรรณยุกต์ลอย (`ThaiText.Fix`)
- ภาพ AI (Higgsfield gpt_image_2_5): คัตซีน 10, พอร์เทรต 5, องค์ประกอบฉาก 39 ชิ้น
- ฉากแยกชิ้น 4 ชั้น ตามสถานที่จริง และแน่นขึ้น
- มอเตอร์ไซค์ประกอบฉาก, ไฟจราจรจริง (รถคันหน้าหยุด, ฝ่าไฟ = ตำรวจเรียก)
- แดชบอร์ดตุ๊กตุ๊กด้านล่างจอ (น้ำมัน/ความสงบ, LCD, นาฬิกา+ความเร็ว, แถบเส้นทาง)
- ขับชิดซ้ายแบบไทย, ตุ๊กตุ๊กวาดใหม่ตาม mood board #1
- เอกสาร: `Devlog.md`, ภาพใน `Screenshots/`, `MoodBoard/`

- ด่านตามสถานที่ 4 ด่าน ด่านละ 2 วิญญาณ เลือก 1 (8 เรื่องราว), อีเวนต์รถชน, รถคันหน้าไม่หยุดมั่ว

## ต้องทำ / ยังไม่ยืนยัน
- รัน **Tools → Last Ride → Build Scene** หลังรับไฟล์ใหม่ทุกครั้ง
- ยังไม่ได้เล่นผ่านทั้งเกมด้วยมือ; เส้นทางพี่ต้นยังไม่ทดสอบ
- ยังไม่ยืนยันว่า SpriteMats แก้ภาพเพี้ยนใน Game view ได้จริง
- ยังไม่ยืนยันว่าแก้รถคันหน้าค้างที่ไฟแดงได้จริง (แก้แบบกันไว้)
- ตำแหน่ง/ขนาดตุ๊กตุ๊กในเลนบนยังไม่ได้ดูภาพจริง; ตุ๊กตุ๊กยังสองล้อ
- เปลี่ยนฟอนต์เป็น Sarabun (OFL) ก่อนส่งงาน
- ระบุการใช้ภาพ AI ในใบสมัคร (ข้อ 17)
- ฉากตำรวจยังไม่มีภาพบุคคล
- ยังไม่ได้เล่นทดสอบด่านใหม่ในเกมจริง (คอมไพล์ผ่านเท่านั้น); ต้องดูว่าฉากวิญญาณ/ตำแหน่ง (!) พอดีไหม
